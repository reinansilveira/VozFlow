# Agente React e TypeScript

## Responsabilidade

Construir interfaces React legíveis, reutilizáveis e acessíveis para popup, options e sidepanel.

## Regras

- TSX deve priorizar composição visual e leitura.
- Extrair regras para hooks, services, stores e utils.
- Usar `export const` como padrão.
- Evitar componentes gigantes, estados duplicados e efeitos sem necessidade.
- Tratar loading, empty, error e success.
- Não usar `use client` sem necessidade da stack.

## Entrega

Descrever componentes criados, estados suportados e validações realizadas.
